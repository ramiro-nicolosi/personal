# Portafolio Personal

Portafolio personal desarrollado con Next.js 16, TypeScript y Tailwind CSS. Este sitio web muestra mi perfil profesional, habilidades, educación y proyectos personales.

## Características

- **Diseño Moderno y Responsivo**: Adaptable a todos los dispositivos
- **Modo Oscuro**: Soporte automático para tema claro y oscuro
- **Componentes Modulares**: Arquitectura limpia y mantenible
- **Optimizado para Performance**: Construido con Next.js 16 y App Router
- **TypeScript**: Código tipado y seguro
- **Tailwind CSS**: Estilos modernos y personalizables

## Secciones

- **Hero**: Presentación principal con nombre y título
- **Sobre Mí**: Información personal y profesional
- **Habilidades**: Stack tecnológico y soft skills
- **Educación**: Formación académica y certificaciones
- **Proyectos**: Portafolio de proyectos personales
- **Footer**: Información de contacto y redes sociales

## Instalación

```bash
# Clonar el repositorio
git clone <tu-repositorio>

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para ver el resultado.

## Scripts Disponibles

```bash
npm run dev      # Iniciar servidor de desarrollo
npm run build    # Construir para producción
npm run start    # Iniciar servidor de producción
npm run lint     # Ejecutar linter
```

## Personalización

Para personalizar el portafolio con tu información:

1. **Hero** (`components/Hero.tsx`): Actualiza tu nombre y título
2. **About** (`components/About.tsx`): Escribe tu presentación personal
3. **Skills** (`components/Skills.tsx`): Añade tus habilidades técnicas y cualidades
4. **Education** (`components/Education.tsx`): Agrega tu formación académica
5. **Projects** (`components/Projects.tsx`): Lista tus proyectos con enlaces
6. **Footer** (`components/Footer.tsx`): Actualiza tu información de contacto
